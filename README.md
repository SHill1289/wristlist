# Wristlist

Wristlist is a fantasy watch-collecting MVP. Users receive a virtual budget, browse a curated watch drop, save watches, and acquire pieces without spending real money.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

Collection data is currently stored in the browser using local storage. The included catalog and watch photography are fictional MVP content.
